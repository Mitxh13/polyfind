# Dataset Provenance and Validation Report

## 1. Provenance and Licensing
- **Source**: Synthetically generated by PolyFind Deterministic Catalog Engine (`src/catalog/seed.ts`).
- **Generation Method**: Deterministic PRNG (Mulberry32) seeded with an integer parameter (default `seed = 42`).
- **License**: **CC0 1.0 Universal (Public Domain Dedication)** / MIT.
- **Privacy & Compliance**: Contains 100% synthetic commercial product titles, descriptions, and metadata. Contains zero Personally Identifiable Information (PII), proprietary vendor content, or copyrighted text.

## 3. Field Distributions and Invariants

Every product record strictly adheres to the authoritative `Product` contract ([docs/contracts.md](file:///C:/mitesh_dev/Projects/polyfind/docs/contracts.md)):

- **Identifiers (`id`)**: Stable formatted alphanumeric string (`prod-0001` through `prod-NNNN`).
- **Price (`price`)**: Floating-point value between $9.99 and $499.99 with 2 decimal precision. Non-negative invariant enforced by MySQL `chk_product_price_non_negative`.
- **Stock (`stock`)**: Integer between 0 and 150 items. Non-negative invariant enforced by MySQL `chk_product_stock_non_negative`.
- **Version (`version`)**: Initialized monotonically at `1` for newly seeded products. Incremented whenever price or stock is updated.
- **Timestamp (`updatedAt`)**: Deterministic ISO 8601 UTC timestamp based on generation sequence.

---

## 4. Integrity Validation Rules

The validator (`validateSeedDataset`) rigorously enforces:
1. **Uniqueness**: Rejects duplicate product IDs and duplicate category IDs.
2. **Referential Integrity**: Verifies that every product references a valid, declared category.
3. **Domain Constraints**: Ensures prices are non-negative, finite numbers, stocks are non-negative integers, and versions are positive integers.
4. **Reproducibility**: Generating with the identical seed produces byte-for-byte identical datasets.
